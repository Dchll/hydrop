# hydrop

局域网文件传输软件

## 依赖
- Flutter 3.41.9
- Drift
- Dio
- AutoRoute
- Riverpod

## 规划新增依赖

- [x] `network_info_plus: ^8.1.0`：已接入，用于补充 Wi-Fi IP、网关、子网掩码、广播地址等网络信息。
- [x] `qr_flutter: ^4.1.0`：已接入，用于在我的页展示本机连接二维码。

## 功能分析

- 当前代码已经具备清晰的数据基础：`lib/data` 只保留 `local` 和 `remote` 两个顶层边界，本地能力通过 Drift + Repository + Riverpod 暴露。
- 网络层已经具备本机地址枚举、UDP 广播/监听、TCP frame 编解码、基础 TCP server/client、轻量测速服务、连接心跳、文本消息收发和文件传输断点续传。
- 消息功能已经覆盖文本、图片、视频、普通文件、超链接、安全跳转、失败重试、删除清空和附件另存为。
- 设备记忆已经覆盖设备 ID、多地址历史、可用性、测速结果、最近连接/断开/传输和最近错误信息。
- UI 层需要避免直接操作 Drift 或网络细节。页面只消费 provider 暴露的状态，发现、连接、消息发送等副作用放到 repository/service 层，保持可测试和可替换。
