# App UI 设计规范

## 页面配色
- 浅色主题为白色蒙层模糊，字体、Icon 黑色
- 深色主题为黑色蒙层模糊，字体、Icon 白色
- 通过蒙层透明度区分不同的层级

## 页面结构
- HyScaffold
    - 全部使用 HyAppBar
    - 背景为纯白或纯黑
- HyAppBar
  - 底层为模糊背景，限制为 AppBar 的高度
  - 左侧为返回按钮，圆形模糊按钮，Icon 使用左箭头
  - 中间为 title 字样，String，字号等样式固定

## 组件
### 按钮
- 按钮为胶囊形（文本按钮）或者圆形（Icon按钮），高度默认 50

### 卡片
- 圆角矩形，背景为两种灰色，对应深浅色主题
- 固定 padding 和 margin
- 未设置高度或者宽度时，根据 child 自适应
